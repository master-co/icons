Simple Icons

造型取捨

folder-kanban沿用 folder 的肩部與底線。Lucide 的三欄較直，Hugeicons 的短欄較疏；16px 把欄頂略提高，保留中欄最短、右欄最長的節奏。
archive-restore參考圖都保有顯眼的盒蓋。初稿的蓋緣太靠近箭翼，將盒蓋下移並縮短厚度，保留兩側凸緣；箭桿越過盒口時切出透明間隙。
id-card採 Lucide 的橫向人像與資料分區。和 Tabler 上方雙區、下方通欄的做法相比，這裡把右側短線留給身份資料，並將肩線下移以分開頭肩。
image-plusLucide 的右上角加號和 Tabler 的右下角加號都保留照片線索。採右上配置避開山脊，拉長加號兩臂，保留原圖左側的日點。
square-plus與兩份方框參考並排後，沿用 square 的邊距與外角，中央十字各留一臂長的呼吸空間；iOS 選單教學需要清楚的方框。
circle-dashed來源都有規律的斷弧。16px 用六段讓間隙在圓頭下仍能分開，20 和 24px 用八段；每段等重，表示未開始。
play-circle兩份圈中播放參考都把三角重心移向右方。沿用看板狀態圓，微微加寬三角，讓 16px 的 sharp 和 rounded 都還看得出內孔。
pause-circle兩份來源以短直筆表達暫停。兩筆對稱、同高，和播放鍵共用外圈；省去描兩個窄矩形會產生的四條緊鄰長邊。
alert-circleHugeicons 的驚嘆號較細，Tabler 的點較重。保留 info-circle 的外圈，將直筆置上，獨立圓點置下，靠距離分開兩筆。
chevrons-up-downLucide 折角張幅較大，Tabler 的 selector 較緊湊。取等寬短翼與開放中央，讓 16px 選單觸發鈕仍有兩個清楚的尖端。
chevrons-left-right沿用上下折角母型轉向，左右展開；兩份來源都是無桿的同軸折角，中央留空讓 Compare 把手可辨認。
arrow-left-right兩份來源都用反向的完整箭桿。依 Gradient 現行按鈕使上排向右、下排向左，各排留出一個箭翼的高度。
arrow-down-right兩份來源都保留折尺形箭翼。直接將既有右上箭頭旋轉四分之一圈，統計升降並排時能維持翼長與軸線重量。
arrow-big-up相較兩份寬身箭頭參考，保留較直的短柄和兩側平肩；收小尖端圓角，避免 soft 與 rounded 在 16px 成為小屋輪廓。
heading-1兩份參考分別使用無襯線與襯線字形。共用無襯線 H，數字 1 用斜起筆和直落筆，底部對齊 H。
heading-2沿用 H1 的字距及基線。比起有襯線的 Tabler，保留較開的數字 2，弧頂接斜腹和水平底線，讓 16px 有清楚方向。
heading-3與同尺寸 H2 回比後保留上下兩段弧腹，中腰停在字面內側。維持三顆 H 同高同寬，減少工具列切換時的跳動。
pilcrow兩份來源都靠左腹與兩條下伸筆建立段落記號。保留開敞的腹孔、雙柱間隙及略長的頂部收筆。
remove-formatting兩份參考都保留斜體文字與右下叉號。採短橫足和向右上傾的主幹，叉號與字腳分開，避免誤讀為刪除線。
hand-clickPhosphor 的接觸弧集中於食指，Tabler 用短放射線。沿用單弧，重畫拇指的回折和握起的指節，縮小時仍可辨認被點到的位置。
resize採用 Tabler 大小框共角的構造，重畫外框的三個開角，拉長上邊以表示尺度延伸。右上留空與左下實框形成差異。
chart-bar-increasingLucide 和 Hugeicons 的直柱配有座標軸。這裡採現有 chart-bar 的空心柱寬、基線和柱距，逐柱升高即可與相鄰報表區分。
brand-html5保留固定版本 Simple Icons 的單色盾牌和反白 5。比較 14px 檔案頁籤及三個原生尺寸後，採 14／17／20 的佔幅維持字腔。
