頁碼格式

頁碼入口可沿用 hash 搭配「頁碼」。真正要區分的是頁首／頁尾位置和 1、i、I 等編號格式，應在設定中直接展示文字值，不再把 # 塞進紙張框。

適用範圍：hash 僅作有標籤的頁碼命令入口；不是以一般數值圖示代替頁碼位置預覽，也不把網站分頁導覽當成文件頁碼。
