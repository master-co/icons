office affine file

已啟用標準連字

使用實際字型的 OpenType 功能；字串內容保持不變。字型需支援相應連字，這裡以 Times 示範。

連字效果取決於目前字型支援的字形組合；具名開關配實際文字預覽能直接顯示結果。固定fi圖稿無法交代不同字型的連字樣式，也不需要另外設計一個字型無關的仿字形。

適用範圍：字型細節與OpenType設定面板。完整標籤區分標準連字、特殊連字與其他字型功能；這裡不將標準與特殊連字合成同一開關。

字型面板 · 字級數值欄位旁的增減控制

文字排版 Typography

16 px

加減號只調整這個具名字級欄位；不改畫面縮放比例。

字級欄位名稱、單位與當前數值已界定操作對象，旁邊的既有加減號即可表達增減。文字樣本實際改變大小，不需再把A字母或方向箭頭和加減號複合。

適用範圍：加減按鈕直接與具名字級欄位成組。若孤立在同時含縮放、增減圖層等命令的無標籤工具列，不能以此證明單獨加減號已足夠。
