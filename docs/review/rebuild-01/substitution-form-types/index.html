field-text → text-cursor

新增欄位 · 類型選擇器

文字游標已傳達可輸入文字，選項標籤明確指出單行。另畫一個框內游標只會縮小必要形狀；控制項實體本身已由表單提供。

適用範圍：搭配單行文字標籤使用；不把游標當作行數資訊。

field-textarea → text

新增欄位 · 與單行文字並列

多行文字的類型名稱應直接顯示。既有 T 可作文字類型的輔助圖，行數由標籤與實際輸入區高度交代；不必把一個迷你文字框塞進 16px。

適用範圍：有完整多行文字標籤的類型選單；T 本身不表示行數，不可單靠它區分單行與多行。

field-number → hash

新增欄位 · 數值類型與數值欄標頭

本輪保留的井字號已提供數值類型所需的不同輪廓；再把它加進輸入框沒有新的必要資訊，數量、單價與總計可共用 hash。

field-dropdown → chevrons-up-down

表單建構 · 選擇一個值的欄位

既有 select 折角已表達開啟選項；單選的限制交給名稱與實際選單狀態。沒有理由再畫縮小的矩形選單外框。

適用範圍：有下拉單選標籤的新增欄位選項；折角本身不表示單選與多選。

field-multiselect → list-checks

表單建構 · 可勾選多個選項

既有 list-checks 的多列勾選已傳達選取清單，搭配多選選項標籤足夠。無需另加一個表單框或第二套勾選列。

適用範圍：對應清單式多選；單一布林值仍用 checkbox，不與此選項混為一談。

field-required → asterisk

欄位標籤與必填設定

星號就是現有的必填提示符號；實際表單保留必填文字與 required 狀態，不需要把星號加到小輸入框中。

適用範圍：星號只作可見輔助提示，欄位名稱、必填文字與程式化 required 屬性仍須保留。

form-section → heading

表單編排 · 插入標題與說明的區段

聯絡資訊
填寫可聯繫的電話與電子郵件。

這個新增動作的可見內容是區段標題，既有 heading 已表達。若涉及跨頁導覽或分頁，應另由頁面控制處理，不以一顆模糊的小表單框兼任。

適用範圍：僅指標題式表單區段；不等同分頁、頁面跳轉或條件分支。
