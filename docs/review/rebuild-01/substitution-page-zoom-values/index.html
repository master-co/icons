縮放方式
同一橫向頁面；符合頁高時寬度可超出視窗，不等同整頁適配。

符合頁寬與符合頁高是縮放方式，並非調整紙張尺寸。move-horizontal／move-vertical 會混淆尺寸拖曳；用具名選項及目前縮放結果即可區分，不以箭頭和頁框再組合一套圖。
