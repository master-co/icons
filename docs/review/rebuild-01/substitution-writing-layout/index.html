此設定改變文字流向，中文字保持正向；不把整個文字框旋轉 90°。字串順序與標點不因切換而改寫。

直書是文字流向、字元朝向及換欄方向的設定，不等同旋轉文字框或 LTR／RTL 字詞方向。具名勾選項與實際直書預覽能直接顯示目前狀態，不需要泛化成一顆容易被解讀為旋轉的字母箭頭。

適用範圍：適用於文件／文字框的格式面板與有標籤的設定選單；不是聲稱既有方向箭頭足以替代所有純圖示工具列。若另有受限工具列需要區分多種文字流向，應連同具體選項重新驗證。
