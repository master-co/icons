這份提案介紹工作區的新設計。圖片與文字的位置取決於排版方式。左右環繞時，文字沿著圖片旁邊排列，經過圖片底部後恢復完整行寬。行內圖片則像較高的文字字元，與旁邊文字共用一條基線。
