瀏覽器分頁選單 · 撤回剛才的關閉動作

最近關閉：產品需求

重開已關閉分頁是撤回關閉動作。undo 搭配完整命令名稱即可，與 history 的歷史紀錄入口分開；不再加分頁框和回轉箭頭。

適用範圍：有文字的分頁選單；不是回上一頁，也不等同開啟歷史清單。若同一工具列亦有編輯復原，需分組及標籤。

window-new → app-window

瀏覽器或應用選單 · 新增獨立視窗

app-window 已表達應用視窗；「另開視窗」標籤交代新增動作。在同一選單中，新分頁可用 plus，不必把加號再次疊進視窗外殼。

適用範圍：具名的新視窗命令；外部連結另開頁面可用 external-link，不能把每個新視窗都理解為開啟外部網址。
