file-pen → pencil

文件詳情 · 狀態管理選單

Haoban 文件詳情已交代目前文件，pencil 可直接表示進入修訂；檔案摺角不提供額外辨認資訊。若同一工具列日後並排不同物件的編輯，應先使用明確標籤，而非預先建立物件加筆的全部組合。

file-down → download

資源列表 · 與新增及篩選並列的匯出按鈕

現有下載箭頭足以表達匯出或下載，CSV 標籤交代檔案類型；Haoban 的實際列表工具列也已使用一般下載圖示，不需要另一個文件外框。

file-up → upload

編輯器媒體節點 · 選擇或更換檔案

媒體節點和按鈕文字已表達檔案對象，既有 upload 表達由裝置加入；Haoban 同一操作已使用一般上傳圖示。文件外框不增加必要的操作差異。

file-stack → layers

方案權益卡片 · 多份文件的文字說明

這個實際使用點要表達不限份數，layers 的重複層片已提供多個物件的線索；文字精確交代報價和請款，不需要重複多個文件摺角。

folder-move → folder-open

移動選取項目對話框 · 目的資料夾選擇入口

移動「專案素材」

目的地：工作區 / 專案

在移動對話框，folder-open 配合「選擇目的資料夾」可識別目的地選擇器；移動操作由對話框標題及確認鈕交代。此替代針對這個完整情境，不能把 folder-open 當成無標籤的移動命令。
