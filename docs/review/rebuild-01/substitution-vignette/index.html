縮圖是效果值預覽；示例以幾何色面呈現邊緣明暗，並非新 SVG 圖示。

在已查實的效果面板裡，暗角是可調整的邊緣明暗值。具名滑桿和效果縮圖可同時交代方向、程度及羽化；再畫框內圓或四角陰影，無法比實際預覽提供更多必要資訊。

適用範圍：適用於具名效果面板及有縮圖的預設選擇器，保留暗角名稱、數量、羽化與零值。不是宣稱所有純圖示行動工具列皆可直接移除此入口；也不把 brightness 或 contrast 當成暗角同義圖。
