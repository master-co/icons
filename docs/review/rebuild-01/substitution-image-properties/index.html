說明的內容需要直接編輯和閱讀；現有欄位不用額外圖示，保留「圖片說明」標籤即可。若另設文字設定入口，才選用 text。與替代文字並列時由標籤及用途說明區分，不把兩顆相近的圖片加文字圖當成必要識別。

適用範圍：實際欄位不需要圖示；text 僅是另設文字設定入口時的可選圖示，不能用兩個相同純圖示取代兩個欄位。

圖片設定 · 無障礙描述與裝飾圖片選項

替代文字與顯示於頁面的圖片說明是不同欄位。

替代文字是輸入內容，不是另一種圖片格式；現有設定面板以「替代文字」及「裝飾圖片，不需描述」清楚交代行為。實際欄位不需要圖示；若另設入口可選 text，欄位仍需要標籤，不以眼睛、耳朵或圖片上疊字代替無障礙語意。

適用範圍：實際欄位不需要圖示，text 僅作可選的文字設定入口；替代文字不得與公開圖片說明混用。
