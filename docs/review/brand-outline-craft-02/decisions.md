> 後續修正：使用者退回 Discord、Reddit、Pinterest 的造型，並要求 outline 可調線寬、在列表直接列出。最新結論見[第三輪回修](../brand-outline-craft-03/decisions.md)。本頁保留前輪歷史，不代表目前定案。

2026-11-18 · 18 個現有 outline 全部逐顆調整。Master 依使用者最新指示不提供 outline；原標誌的路徑、比例與光學配置維持不變。

[原版／前稿／採用稿及六組連結列](index.html) · [24px 總覽](screenshots/overview-light-2.png) · [前一輪選型紀錄](../brand-outlines/decisions.md)

每顆先比原標誌的形狀與比例，再檢查前一輪的線條構成。以原生 16／20／24px 檢查明暗背景、DPR 1／2、文字旁的 55% 前景與混排；64px 只用於檢查轉折。這是 Codex 的視覺審查紀錄，沒有宣稱維護者已核准或做過人類辨識研究。

這輪保留品牌本身的角與曲面；不把所有標誌套上同一種圓角。適合沿用外邊界的圖形，將線條往內建立，以免外描邊撐胖輪廓。眼點、字樣、聲波與紙飛機保留必要的實心細節。

## 混排結論

通訊列的 WeChat、Telegram、LINE 透過外框減輕墨量，與 WhatsApp 同列仍保留各自氣泡、機翼及字樣。作品集裡 GitHub 的頭型、尾巴與兩個開放腳端仍能辨識；Master 專案列使用原 Master 加上 GitHub／GitLab 線條版。社群、影片音樂、收藏支持列也保留原標誌作比較。Facebook、Vimeo 的窄字身在 16px 比圓框類輕；本輪採保留內孔和比例，沒有硬加粗填滿空腔。Telegram 圓框稿與一般 send 可由框及飛機構成區分。

## 來源與重建

WeChat 保留 TDesign 的雙泡構成與 MIT 聲明，重新調整曲線、尾尖及眼點；不再聲稱路徑未改動。Tabler 派生版本保留完整 MIT 聲明。原品牌的 Simple Icons 輪廓另外記錄在 source.identitySource，與線條構成來源區分。來源原檔、前稿、編輯母稿、固定墨形與各自 SHA-256 均保留。這些是 Master 的圖示詮釋，未宣稱品牌官方核准。

執行 node scripts/build-brand-outlines.mjs 可從 references/brand-outlines/authoring 重建 18 顆；data-ink=inside 只用於編輯母稿，匯出為標準 currentColor / evenodd 路徑。執行 node scripts/review-brand-outline-craft.mjs 產生本頁及明暗 DPR 1／2 圖表。

Master 的探索稿只留在 drafts 作歷史記錄，不進 manifest、匯出名稱、品牌卡切換或 SVG 套件。OpenAI／ChatGPT 繼續共用同一張品牌卡與同一圖稿，既有別名匯入保留。
