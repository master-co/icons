# Craft 03：280 顆逐項工藝審查

以 commit 13587b62 的 280 顆為固定基準，依 Master Icons skill v0.5.1 完成 28 批、每批 10 顆的逐項來源與目視審查。精修 22 顆，保留 258 顆。原始 48 名稱完整保留，其中本輪幾何變更只有 copy、bell-off。使用者肯定的 indent-increase、indent-decrease、megaphone、handshake、ticket，以及最新 layers 均維持原稿。

初輪每批並列兩份固定來源、真實前稿、目前圖稿、三尺寸三圓角、明暗背景與 55% 前景。修圖後以 revised-a 至 revised-f 分次重看，再對全部 28 張 Chromium DPR 2 原生明暗合併板逐張複核。560 份來源引用 checksum 全部符合。輸出 hash 綁定實際母版，不以建置成功代替目視批准。

本子代理未執行建置、React 消費端、跨瀏覽器完整整合，也未 commit。這些交由主代理統一執行；本報告只記錄已完成的原生幾何及 Chromium DPR 1／2 視覺檢查。全部仍為 alpha 候選，未將主觀審查當成使用者定案。

## 精修與保留的依據

- 20 顆修改涉及遮擋切口或完整母型：使用既有製作端 PathKit，以實際前景墨跡的外擴輪廓扣除背景。未改公開 API，未改 shared／occlusion helper。
- folder-up、folder-down 的 16／20px 內箭頭收短；原 16px 下箭尖到框的可見空白僅約 0.08px。新版底部約 0.75px 淨空，24px 母版保持不變。
- clipboard-pen 第一版正確布林扣除仍留下右下孤立碎片；將筆整體在 24-grid 右移 1.5、下移 2，保持固定外擴量，讓前景實際遮住該角。未刪除任意小碎片，也未放大矩形缺口。revised-d／e 是中間探索，revised-f 與 final 才是採用結果。
- mail-check 勾號右移 0.75，消除外框右下殘片；保持與 mail-x 同一母型。
- filter-clear 原有 X 與漏斗本身已有足夠空白，保留。users、images、tags、messages 為可推回母型的局部露出構造，沒有實際碰撞，保留。layers 三層實際可見寬度與端部回弧已改善，保留。coins、copy 則需要由完整後景扣除，已修。
- 正常結構接點如 ban、crop、USB、字形、格線、箭頭接點、車輪與車架沒有套用遮擋裁切。

## 效果判斷

逐顆紀錄虛線、透明度與漸淡採用／不採用理由；維持既有 ticket／file-archive 的語意撕線／拉鍊方段，未新增無語意效果。chart-area 的逐筆 20% 面積填色保留；主輪廓維持實色。明暗、16px、55% 前景均有本輪證據。
