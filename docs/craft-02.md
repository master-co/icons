# Craft 02：以五顆修正經驗重審全庫

2026-11-16。使用者肯定 indent-increase、indent-decrease、megaphone、handshake、ticket 的精修，並明確要求一位子代理依這些教訓，重新逐顆審查與優化全部圖示。本輪以 commit `54a2a44` 的 280 個命名圖稿為基準，保存真實前稿及第一輪逐項紀錄。

## 審查依據

- **動作必須作用於內容。** 縮排的中行長短與箭頭共同表達方向；其他操作同樣檢查動作、主體與落點的關係，不機械套用縮排造型。
- **曲線必須解釋構造。** 擴音口的張開、握柄的彎折、手掌包覆與指節回折是辨識訊號。不能用直線多邊形加圓角取代物體曲面，也不能把尖角本身有語意的圖形全改成弧線。
- **局部角型服從部件。** 票券撕線採平切，外框仍可微圓。逐顆檢查端帽、尖端、接角與曲面；不存在全庫一律圓或一律平的捷徑。
- **小尺寸重新分配空間。** 以主輪廓、必要內孔及狀態優先，檢查描邊後的實際空隙、遮擋、重心與密度。保留有用途的細節，移除無辨識價值的微孔。

## 分工與證據

子代理獨立按 28 批逐顆檢視固定來源與現有圖稿，提出具體保留／修改理由，修改有明確缺陷的原生幾何。主代理核對改動、前後稿、跨尺寸與跨瀏覽器輸出，整合中央紀錄及 skill。渲染成功不代替目視判斷，既有通過狀態不自動沿用。

第二輪仍保持 280 個命名圖稿、182 個基本概念、2,520 份 SVG。使用者肯定的五顆為已確認的設計方向；全庫使用者最終定案與工程通過仍分開記錄。

其餘 278 顆保留，包含使用者肯定的五顆。原始 48 本輪全數不動。主要辨識線索已成立的圖示不為了增加修改數而重畫；sort 的行長、align 的內容對齊、briefcase 的包蓋曲面就是保留案例。

本輪沒有新增虛線或透明度。highlighter 與 phone-off 都用實線輪廓表達用途，不以淡化隱藏接縫。ticket／file-archive 的平切虛線與 chart-area 的次要透明面積維持前輪版本，逐顆重新記錄效果判斷。
