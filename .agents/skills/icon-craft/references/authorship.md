# 研究參考、改作與授權紀錄

Master Icons 研究成熟圖庫的語意與構造，並在自己的幾何系統中製作圖稿。來源分類依實際製作過程判斷；使用自家 primitives、重新寫成程式或改變圓角，本身不能證明完全獨立創作。

## 區分來源角色

| 實際製作方式 | 紀錄方式 |
| --- | --- |
| 從語意與自家幾何設計，未移植他人具體圖稿 | 記錄製作與審查過程；不把看過的圖庫自動列為圖稿作者 |
| 比較通用符號、公開規格與多種設計解法 | 保存研究依據、原稿版本及具體觀察，與圖稿的改作來源分開 |
| 複製 path、描圖或沿用可識別的具體圖稿後改形 | 如實記錄採用／改作、修改內容及適用授權聲明 |
| 比較頁展示上游原始 SVG | 保存原作者、固定版本、資產路徑與授權；不混入 Master 作者欄 |

來源紀錄包含圖庫名稱、原始檔名與路徑、版本或 commit、checksum、來源角色、授權檔及具體修改。只有家族／構造對照時明記，不能因檔名相同就當作同語意原稿。參考素材的固定版本與歷史基準應保持可追溯。

## 有既定識別規範的功能符號

候選若已有官方識別圖或跨產品識別規範，先核對該圖形的用途、尺寸及使用／改作條件，再決定是否進入一般描邊重繪流程。通用功能名稱不代表其慣用圖形可以任意重設；例如 passkey 不可僅憑圖庫收錄 user-key，就把人物加鑰匙認定為等義原稿。相近家族參考仍須維持家族分類，不能以第三方圖庫的開源授權推定官方識別圖也允許相同改作。若不適合重繪，明確記錄官方資產整合或不收錄的決定及理由，不為湊數創造近似符號或加入誤導別名。

## 保留既有聲明

`packages/icons/src/provenance.mjs`、`THIRD_PARTY_NOTICES.md` 與 `licenses/` 是現有來源及授權紀錄。當前包含 12 顆 Hugeicons Free 研究重繪的保留聲明，以及 `megaphone`、`handshake`、`layers` 的 Lucide 改作紀錄。品牌資產另見 `packages/icons/src/brands.json` 與 notices 的品牌章節，不以本 skill 的介面圖示規則重設標誌或改列來源。精修後仍保留相關歷史；不能因外觀變動或新增 skill 就宣稱從未沿用素材。

若實際製作方式與分類不符，逐項核對圖稿、歷史及適用授權後修正 metadata；不要批次刪除 notices 或 licenses。來源角色由比較轉為實際採用／改作時，同步來源紀錄及單檔 SVG、ZIP、框架套件的適用聲明。

比較原稿與正式圖稿分開封裝。比較資產不納入正式圖示套件，但其授權仍隨比較素材保留；正式圖稿所需的上游聲明不能因比較素材未打包而移除。

## 公開介紹與產品介面

README 聚焦 Master Icons 的尺寸、角型、圖形取向與使用方式，連到完整來源紀錄。普通圖庫介面不另加逐顆研究來源標籤；這不取代適用授權所需的聲明。逐一依上游條款處理，不能把某一授權的展示要求推廣到所有素材。

不宣稱所有圖稿完全獨立原創，不以「由程式生成」作為無來源的證據。也不因做過比較，就將無實際沿用關係的圖稿標成某圖庫改作。Master Icons 與參考專案沒有隸屬或背書關係。

如實說明 AI 輔助製作與檢查，區分自動化測試、AI 目視紀錄及維護者審定。用具體證據描述改善與限制，不宣稱全庫無瑕疵、所有尺寸像素完美，或把 alpha 審查結果寫成品質保證。
