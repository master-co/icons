# 研究參考與圖稿來源

使用者偏好：Master Icons 以自家幾何製作，產品介面不逐顆掛參考圖庫來源。研究過一個圖庫，不自動把它記成作品作者；參考共同設計原則也不是匯入素材。

| 實際製作方式 | 處理方式 |
| --- | --- |
| 從語意與自家 primitives 設計，未移植他人具體圖稿 | Master 自行製作；不增加競品作者／來源標籤 |
| 閱讀公開規格、看市場樣式、比較通用符號 | 研究筆記可引用依據；不把研究 bibliography 複製成每顆 icon 的 source |
| 複製 path、描圖，或沿用可識別的具體圖稿後改形 | 如實記錄引用／衍生及適用 notices；重寫成程式或改圓角本身不會自動改變來源 |
| 比較頁展示外部原始 SVG | 名稱、固定來源與適用授權屬於該比較資產，不混進 Master 作者欄 |

不需要在普通 icon UI 強塞技術來源說明。內部紀錄、適用授權文字和使用者介面標籤是不同事情；[MIT 條款](https://opensource.org/license/mit) 對其複本或實質部分有保留聲明的條件，沒有要求每個使用場景都加一個可見的「來源」按鈕。

初版 12 個 study-redraw 的保守 notices 是既有歷史，不能因為新增 skill 就宣稱從未參考或證明都非衍生。此次把逐顆顯示移除，既有聲明保留。若後續要求重新分類，按實際製作過程與資產逐項判斷；不能把「由程式生成」當作無來源的證據。

pilot / 代表圖示只是審稿集合，不能決定版權歸屬。新增圖示也不因被拿來比較，就自動繼承對照圖庫的作者名稱。若發現分類不符，精確修正相關 metadata，不刪整個 licenses 資料夾。
