# 造型工藝

## 中立與語意

一顆圖示對應一個主要概念。先列出必要辨識訊號與容易混淆的鄰居：例如 download 要有落點／承接物以區別 arrow-down；user 與 users 的差別是人數，不必另外改頭部形狀。modifier 應從屬於母型，不和主體搶重心。

在沒有特定品牌要求時，維持正面、平面、單色；避免表情、擬人化、裝飾閃光、玻璃反光、過度透視、誇張機械齒或帶特定產品外觀的設備。必要時用保留核心特徵的抽象形狀，不假設地區特定郵筒、貨幣、手勢人人都懂。文字、數字與單位不要作為唯一辨識依據。

中立仍可有自己的比例、微圓與疏密；不要為「原創」把常見操作改成陌生比喻。對有歧義的符號，用產品標籤說明用途，而非堆更多圖形。

## 外輪廓、重心與比例

先看 16px 的輪廓，再看大圖的構造。用 circle、square、folder 等本專案圖形作同尺寸錨點；按類型比較，不要求每顆有相同外接框、墨量或面積。

圓形可能需要比方形更大的外接尺寸，尖端可能需要 overshoot；這些是待觀察的補償，不是固定「放大 10%」或「移動 1px」規則。非對稱圖形先改內部重量分配，再視需要移動整體，避免為修正一個尺寸破壞其他尺寸。

檢查可見上、下、左、右邊界與鄰近留白。低重心的 bell、底部有框的 tray、窄直向 file 不應只依外接框中心排齊。放進文字旁再看，不把設計展示卡置中當成實際使用情境。

## 曲線與轉折

選最簡單、足以描述輪廓的圖元。圓用 circle / arc；有必要的非圓曲線才用 Bézier。不要為降低節點數犧牲曲線，也不要用很多短線拼出不平順的弧。

相接曲線先確認端點一致（位置連續），再確認切線方向相同且控制柄不折返（切線連續）。曲率要在原生與放大圖看是否突然加速；不要把「所有路徑必須高階連續」套在本來需要尖角的符號。

看 shoulder 進 dome 的接點、heart 中央凹口與底尖、folder tab 的轉折、齒輪齒根、file fold 的交會。消除無意義的小尾巴、重疊描邊、微小自交、收筆凸點與幾乎碰到的端點。尖端必須像尖端，圓角不能抹掉星星或警告三角形的辨識性。

## 負空間與結點

檢查的是描邊之間的可見空隙。兩條中心線距離 d、寬度 w1 / w2，局部平行時空隙約 d − (w1 + w2) / 2；斜角、端點與曲線要看實際 raster 邊界。不要以中心距離冒充空隙。

細節太擠時依序考慮：移除次要訊號、重排留白、略改主體比例、縮短內線。不要先把整套描邊變細。已經相連的線應清楚地連起來；刻意分離的元素要有穩定間隙，避免似接非接的 tangency。

分開處理 frame 半徑、折角半徑、箭頭尖端與齒根。大外框可以更圓，小內孔不能因此被吃掉。外框收圓後再次檢查角落附近的點、文字線與 modifier。

## 視覺重量與家族

同樣的 stroke-width 不代表同樣重量。線很多、交叉很多、內部很窄的圖示會更黑；開放輪廓、長斜線和小圓點可能顯得更輕。先減密度與清理交叉，再調整比例；偏差確實仍存在時，做局部且可說明的光學補償。

file / file-text、folder / folder-plus、bell / bell-off 等共用母型。附加狀態只改所需區域；不要為放入 plus 把整個資料夾突然換成另一個比例。刪除斜線類圖示需要清楚遮擋關係與切口，不能用背景色塗掉路徑造成透明或深色背景失效。

## 具體診斷用語

| 觀察 | 有效下一步 |
| --- | --- |
| 16px 的兩個孔黏在一起 | 放寬孔距／減少孔數，重看原生大小 |
| gear 比旁邊 circle 黑 | 檢查齒根密度、內孔、交叉，先不改全域描邊 |
| rounded 比 soft 小一圈 | 比較尖端縮短、弧角裁切與可見範圍，調局部幾何 |
| file-text 下緣像黑塊 | 減內線、增加底部空隙，保留文件訊號 |
| 曲線轉入直線時鼓包 | 檢查切線、重疊端帽或多餘短段 |
| 某圖像其他品牌產品 | 抽象掉特定外殼／裝飾比例，回到語意母型 |

避免只寫「更精緻」「不夠高級」「更中立」。指出哪個尺寸、哪段輪廓、與什麼相鄰圖形相比，以及預期改善。

## 從實際精修學到的構造判斷

- **接點要有共同依據。** mouse-pointer 的尾線應接凹口的同一座標；timer 的斜按鈕可從圓心、半徑和角度求交點。小微縫被端帽蓋住，仍會讓 sharp 或其他 DPR 出現不同墨量。不要只把端點拉長來掩飾位置誤差。
- **動作也能由內容表達。** 參考 Tabler 的 indent：增加縮排時中行相對上下行內縮，減少時向外伸出；箭頭和文字的空間關係一起承載語意。配對圖示不必只是鏡射一個箭頭。文字行本身保持閱讀方向與共同右緣。
- **結構曲線與裝飾圓角分開。** megaphone 的擴音口上下曲線、彎握柄，以及 handshake 的拇指包覆和手指回折，是物體辨識的一部分；不能只畫直線多邊形再提高 radius。sharp 可保留真實曲面，只讓適用的接角變銳。
- **細節必須接在物件上。** 手指縫要交代握合／遮擋，不能懸在掌內作裝飾。沿 Lucide 的成熟構造研究曲面與指節時，先建立完整手掌輪廓，再縮短 16px 的內指縫；不是機械刪除外輪廓的一個手指。
- **圓滑不等於更好。** ticket 撕線採平端、齒軌保留短矩形，和微圓外框並不衝突。照顧構造差異，比全部線條套相同圓帽更重要。

上述是 Craft 01 經實際 A/B 的經驗。它們不要求下一輪一定重畫同名圖示，也不代表每個物件都要更曲、更細。若已形成刻意的線條交接（例如 @、鎖梁、圖表分隔），不要為了增加空白而剪斷語意。

## 將案例用於其他圖形

Craft 02 的獨立複審發現兩個可延伸的判斷：

- **工具的工作端比共用筆桿更有辨識力。** highlighter 需要寬平的筆尖，pencil 保留尖端，paintbrush 以柔軟筆毛收束。只在同一支尖筆下方加一條橫線，會讓不同工具過於接近。工作刃可以保留平直角，即使筆身採微圓；仍須檢查筆尖、筆身及畫線之間的空隙。
- **狀態圖示也須繼承母型的工藝。** phone-off 的遮擋切口是必要差異，聽筒兩端的角型卻應和 phone 一致。製作 off／disabled 時，先沿用母型曲線再設計切口，不因多了一條斜線就退回較粗略的輪廓。必要時共用局部曲線或角型係數，避免兩個版本日後漂移。

兩者都是語意與家族的局部修正，不要求全庫套相同工具尖端或圓角數值。已能清楚區分的 sort、align、briefcase 等可保留，並寫下具體理由。


## 遮擋輪廓避讓：外輪廓等距淨空

穿越主體的狀態斜線，或疊在角落的 ×、−、勾號、鎖頭、放大鏡等，是前景遮擋物。先定前後關係，再由前景的**實際可見輪廓**產生等距外擴（offset contour），從背景主體的可見筆畫區域作布林差集（Boolean difference）。這個透明隔離帶稱為 knockout clearance；它是幾何負空間，不是描白邊。

若前景可見區域為 F、淨空為 c，避讓區是 F 與半徑 c 圓盤的 Minkowski sum／形態膨脹；背景輸出為 B 減去該避讓區。實作不強制特定函式庫，但結果需符合下列契約：

- **從墨線外緣量淨空。** 包含前景描邊寬、端帽及尖角，不從中心線或外接矩形算距離。同一原生尺寸使用共同淨空起點；16／20／24 可各有光學值，例外需具體記錄。
- **裁切邊緣服從遮擋輪廓。** 斜線附近的切面跟隨其平行外擴邊緣，× 跟隨各臂，鎖頭跟隨鎖梁與鎖體剪影。不要用同一方形缺角切掉所有右下徽標，也不要裁完後再加圓端帽侵入淨空。
- **區分筆畫與物件剪影。** 斜線、×、− 按筆畫聯集避讓；鎖頭等封閉物件連同內部形成遮擋剪影，避免背景線穿過鎖體或鎖梁孔。不要把開放符號一律填成外接框。
- **保留母型。** 優先從完整、已精修的主體裁切，不能沿用舊缺口再加大，否則原本過寬的空洞無法恢復。背景剩餘曲率與比例保持母型一致。
- **真透明且無碎屑。** 不用背景色、透明度或厚白描邊蓋住錯誤。檢查裁切後的孤立細屑、短刺與微孔；若布林結果產生無語意碎片，重排標記或主體，不以擴大整個方形缺口掩飾。
- **不要誤切結構。** 內置減號、圓內叉號若本來不碰邊框，不需製造缺口；ban 的斜桿連接圓環、箭頭與桿、鉸鏈與外框等語意連接也不套遮擋規則。

驗證含三尺寸、三角型、明暗與透明棋盤底、低對比、原生與放大切口。以幾何差集檢查背景沒有侵入避讓區，並驗證接觸段確實到達外擴邊界；只證明兩物件不碰撞，不足以證明淨空一致。

Clearance 01 試作的共同淨空為原生 16／20／24 的 0.75／1／1.25px，尚待使用者確認全庫推廣。製作端可將描邊展開後裁切，輸出普通單色 path；保留可編輯母型與遮擋物，不把布林輸出當成唯一原稿。不要新增公開效果參數或把幾何引擎送進消費端套件。
