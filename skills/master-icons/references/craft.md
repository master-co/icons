# 造型工藝

## 中立與語意

一顆圖示對應一個主要概念。先列出必要辨識訊號與容易混淆的鄰居：例如 download 要有落點／承接物以區別 arrow-down；user 與 users 的差別是人數，不必另外改頭部形狀。modifier 應從屬於母型，不和主體搶重心。

在沒有特定品牌要求時，維持正面、平面、單色；避免表情、擬人化、裝飾閃光、玻璃反光、過度透視、誇張機械齒或帶特定產品外觀的設備。必要時用保留核心特徵的抽象形狀，不假設地區特定郵筒、貨幣、手勢人人都懂。文字、數字與單位不要作為唯一辨識依據。

中立仍可有自己的比例、微圓與疏密；不要為「原創」把常見操作改成陌生比喻。對有歧義的符號，用產品標籤說明用途，而非堆更多圖形。

## 外輪廓、重心與比例

先看 16px 的輪廓，再看大圖的構造。用 circle、square、folder 等本專案圖形作同尺寸錨點；按類型比較，不要求每顆有相同外接框、墨量或面積。

圓形可能需要比方形更大的外接尺寸，尖端可能需要 overshoot；這些是待觀察的補償，不是固定「放大 10%」或「移動 1px」規則。非對稱圖形先改內部重量分配，再視需要移動整體，避免為修正一個尺寸破壞其他尺寸。

檢查可見上、下、左、右邊界與鄰近留白。低重心的 bell、底部有框的 tray、窄直向 file 不應只依外接框中心排齊。放進文字旁再看，不把設計展示卡置中當成實際使用情境。

## 曲線與轉折

選最簡單、足以描述輪廓的圖元。圓用 circle / arc；有必要的非圓曲線才用 Bézier。不要為降低節點數犧牲曲線，也不要用很多短線拼出不平順的弧。

相接曲線先確認端點一致（位置連續），再確認切線方向相同且控制柄不折返（切線連續）。曲率要在原生與放大圖看是否突然加速；不要把「所有路徑必須高階連續」套在本來需要尖角的符號。

看 shoulder 進 dome 的接點、heart 中央凹口與底尖、folder tab 的轉折、齒輪齒根、file fold 的交會。消除無意義的小尾巴、重疊描邊、微小自交、收筆凸點與幾乎碰到的端點。尖端必須像尖端，圓角不能抹掉星星或警告三角形的辨識性。

## 負空間與結點

檢查的是描邊之間的可見空隙。兩條中心線距離 d、寬度 w1 / w2，局部平行時空隙約 d − (w1 + w2) / 2；斜角、端點與曲線要看實際 raster 邊界。不要以中心距離冒充空隙。

細節太擠時依序考慮：移除次要訊號、重排留白、略改主體比例、縮短內線。不要先把整套描邊變細。已經相連的線應清楚地連起來；刻意分離的元素要有穩定間隙，避免似接非接的 tangency。

分開處理 frame 半徑、折角半徑、箭頭尖端與齒根。大外框可以更圓，小內孔不能因此被吃掉。外框收圓後再次檢查角落附近的點、文字線與 modifier。

## 視覺重量與家族

同樣的 stroke-width 不代表同樣重量。線很多、交叉很多、內部很窄的圖示會更黑；開放輪廓、長斜線和小圓點可能顯得更輕。先減密度與清理交叉，再調整比例；偏差確實仍存在時，做局部且可說明的光學補償。

file / file-text、folder / folder-plus、bell / bell-off 等共用母型。附加狀態只改所需區域；不要為放入 plus 把整個資料夾突然換成另一個比例。刪除斜線類圖示需要清楚遮擋關係與切口，不能用背景色塗掉路徑造成透明或深色背景失效。

## 具體診斷用語

| 觀察 | 有效下一步 |
| --- | --- |
| 16px 的兩個孔黏在一起 | 放寬孔距／減少孔數，重看原生大小 |
| gear 比旁邊 circle 黑 | 檢查齒根密度、內孔、交叉，先不改全域描邊 |
| rounded 比 soft 小一圈 | 比較尖端縮短、弧角裁切與可見範圍，調局部幾何 |
| file-text 下緣像黑塊 | 減內線、增加底部空隙，保留文件訊號 |
| 曲線轉入直線時鼓包 | 檢查切線、重疊端帽或多餘短段 |
| 某圖像其他品牌產品 | 抽象掉特定外殼／裝飾比例，回到語意母型 |

避免只寫「更精緻」「不夠高級」「更中立」。指出哪個尺寸、哪段輪廓、與什麼相鄰圖形相比，以及預期改善。
