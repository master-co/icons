## Dynamic icons \{#dynamic\}

Svelte is a required peer dependency. Install Svelte 5 in your application and [add the local package](/guide/getting-started).

```svelte
<script lang="ts">
  import { SearchIcon } from '@master/icons-svelte';
  let element = $state<SVGSVGElement>();
</script>

<SearchIcon size={20} corner="rounded" label="Search" bind:ref={element} />
```

The dynamic entry includes all nine optical size and corner combinations, along with their supported stroke widths, for each imported icon. It shares the same geometry as React and SVG. `size` selects the nearest optical drawing; `corner` defaults to `soft`.

## Fixed icons \{#fixed\}

```svelte
<script lang="ts">
  import { SearchIcon } from '@master/icons-svelte/16/soft';
</script>

<button aria-label="Search"><SearchIcon /></button>
```

Fixed entries include only one optical size and corner style. Replace `16/soft` with any combination of `16`, `20`, `24` and `sharp`, `soft`, `rounded`. Fixed components do not accept `corner` or `opticalSize`; `size` only scales the selected drawing.

## Framework behavior \{#behavior\}

Native `.svelte` sources are compiled by your application for the server and browser. Use Svelte 5 event props such as `onclick`. `bind:ref` exposes the SVG element; changing `size` or `corner` updates the drawing.

Unlabeled icons are decorative. Use `label`, `aria-label` or `aria-labelledby` for a meaningful icon, or label the enclosing button. See [accessibility](/guide/accessibility).

## Custom stroke width \{#stroke-width\}

Use `strokeWidth` with either entry. It selects precomputed geometry, including cutouts and masks, rather than only changing the SVG stroke attribute. The explorer copies the component import with this prop and keeps SVG markup exclusive to the SVG format.

```svelte
<script lang="ts">
  import { SearchIcon } from '@master/icons-svelte/24/soft';
</script>

<SearchIcon size={48} strokeWidth={2} />
```

Widths use native viewBox units in 0.25 increments. The ranges are 0.75–1.5 for the 16 px master, 1–2 for 20 px, and 1.25–2.5 for 24 px. Values outside the selected master’s range are clamped; nonpositive, nonfinite or non-quarter-step values throw an error. Omit the prop to use the original drawing. Display `size` scales the entire drawing, including its stroke. Brand silhouettes keep their original shape. Fixed imports include only their selected optical size and corner, with its supported widths; unused icons still tree-shake.
