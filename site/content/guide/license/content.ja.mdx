## Master Icons \{#master\}

Master Icons は [MIT ライセンス](/LICENSE.txt)のオープンソースです。再配布時は該当する著作権表示とライセンス表示を保持してください。

## ブランドアイコン \{#brands\}

`brand-` コレクションには、Simple Icons の図案、各ブランドの公式素材、Master のロゴに加え、Dcard のラスター画像をトレースしてベクター化した図案が含まれています。Dcard の図案には制作過程の記録があります。図案のライセンスはコードのライセンスとは別です。Vue の図案には追加許諾付きの CC-BY-NC-SA-4.0 が適用されます。JavaScript と GitHub Copilot の図案では提供元の MIT ライセンス表示を保持し、Microsoft と OpenAI の素材には各社の利用条件が適用されます。出典ごとの権利表示は、`licenses/brand-additions.txt` などにまとめ、パッケージとダウンロードファイルに同梱しています。Dcard の図案は過去のアプリロゴをもとにしています。当時のガイドラインでは最小サイズが 48 px と指定されており、それより小さいサイズは見え方を確認するためのプレビューです。ガイドラインへの適合を示すものではありません。ブランド名とロゴはそれぞれの権利者に帰属し、コードのライセンスは商標権を付与しません。個々の出典とバージョンは[第三者の権利表示](/THIRD_PARTY_NOTICES.md)を参照してください。

## 翻案した図案 \{#sources\}

一部の図案は Lucide、Tabler、Phosphor、Hugeicons Free、Iconoir、Material Design Icons などの構成を参考に翻案しています。翻案した図案については、元の MIT、ISC または Apache 2.0 のライセンス表示を、個々の SVG とパッケージ、ダウンロード用アーカイブに残しています。各アイコンの出典は[第三者の権利表示](/THIRD_PARTY_NOTICES.md)に記載しています。

`teapot` のふたは OpenMoji の絵文字を翻案しています。この図案と改変物には CC BY-SA 4.0 が適用され、MIT ライセンスの対象外です。ライセンス表示の全文は SVG とパッケージに含まれます。

独立したレビューツールには比較用の原図も含まれます。これらの研究資料は Master Icons のパッケージやサイトとは別に保管し、元のライセンスを同梱しています。
