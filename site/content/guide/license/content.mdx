## Master Icons \{#master\}

Master’s code and original interface drawings use the [MIT license](/LICENSE.txt). The core package and SVG archives include the license and third-party notices. Keep the applicable notices when redistributing artwork.

## Brand icons \{#brands\}

Brand names and marks belong to their respective owners. The [third-party notices](/THIRD_PARTY_NOTICES.md#brand-artwork) record the artwork sources and any separate usage terms.

## Adapted work \{#sources\}

Some drawings adapt work from other icon libraries. For example, the OpenMoji lid in `teapot` is shared under CC BY-SA 4.0, which also covers the adapted drawing. See the [teapot notice](/licenses/teapot-openmoji-CC-BY-SA-4.0.txt).

Single SVGs include the applicable artwork notice whether copied, downloaded or served from an npm CDN. The [research credits](/THIRD_PARTY_NOTICES.md#research-credits) identify the comparison artwork used in the review tool.
