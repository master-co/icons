## SVG 檔案 \{#svg\}

可從[圖庫](/icons)下載單一 SVG 檔案，或下載某一尺寸與圓角的全部圖示 ZIP 壓縮檔，內含授權文件。[安裝 `@master/icons`](/guide/getting-started#install) 後，同樣的檔案位於套件子路徑 `@master/icons/svg/{size}/{corner}/{name}.svg`，例如 `@master/icons/svg/20/soft/search.svg`。

Inline SVG 使用 `currentColor`。透過 `<img>` 載入的外部 SVG 不會繼承周圍文字的顏色。

## JavaScript 渲染器 \{#javascript\}

```js
import { Search, renderSvg } from '@master/icons';
const svg = renderSvg(Search, { size: 20, corner: 'soft', label: 'Search' });
```

`renderSvg` 回傳 SVG 標記，請搭配本套件可信任的圖示定義使用。圖示定義的名稱不含元件使用的 `Icon` 字尾。`size` 控制顯示尺寸；`opticalSize` 可明確指定 16、20 或 24，預設選擇最接近的光學圖稿。

| 選項 | 預設 | 行為 |
| --- | --- | --- |
| `size` | `24` | 顯示尺寸，須為有限正數 |
| `opticalSize` | `'auto'` | 16、20 或 24 母版；`auto` 取最接近者，18 與 22 取較大者 |
| `corner` | `'soft'` | `'sharp'`、`'soft'` 或 `'rounded'` |
| `strokeWidth` | 原生 | [線寬](/guide/stroke-width)，以原生單位與 0.25 為級距 |
| `color` | `'currentColor'` | 圖稿的顏色 |
| `label` | 無 | 未提供時 SVG 為 `aria-hidden`；提供時 SVG 加上 `role="img"` 與標籤 |
| `direction` | `'ltr'` | `'rtl'` 會鏡像具方向性的圖示 |

設定 `direction` 為 `rtl` 時，只有 `arrow-left`、`arrow-right`、`chevron-left`、`chevron-right`、`chevrons-left`、`chevrons-right`、`undo` 與 `redo` 會鏡像。
