## 動態圖示 \{#dynamic\}

React 是必要的 peer dependency。請在應用程式安裝 React 18 或 19，並[安裝 `@master/icons-react`](/guide/getting-started#install)。

```tsx
import { SearchIcon } from '@master/icons-react';
<SearchIcon size={20} corner="rounded" label="Search" />
```

動態入口會為每個匯入的圖示包含九種光學尺寸與圓角組合，以及各組合支援的線寬圖稿，與其他框架及 SVG 共用相同幾何。`size` 會選擇最接近的光學圖稿；`corner` 預設為 `soft`。

## 固定圖示 \{#fixed\}

```tsx
import { SearchIcon } from '@master/icons-react/16/soft';
<button aria-label="Search"><SearchIcon /></button>
```

固定入口只包含一種光學尺寸與圓角。可將 `16/soft` 換成 `16`、`20`、`24` 與 `sharp`、`soft`、`rounded` 的任意組合。固定元件不接受 `corner` 或 `opticalSize`；`size` 只會縮放所選圖稿。在介面中使用一致的固定入口，即可統一視覺語言。

## 框架行為 \{#behavior\}

元件接受標準 SVG props 與事件，並透過 `forwardRef` 將 ref 傳遞至 SVG 元素。元件可在伺服器與瀏覽器渲染，不需要僅限用戶端的包裝。

沒有標籤的圖示會視為裝飾。對有意義的圖示使用 `label`、`aria-label` 或 `aria-labelledby`，或替外層按鈕命名，詳見[無障礙](/guide/accessibility)。

## 自訂線寬 \{#stroke-width\}

動態與固定入口都接受 `strokeWidth`，以原生單位與 0.25 為級距。它會選用重新繪製的幾何，而非修改 SVG 的線寬屬性。

```tsx
import { SearchIcon } from '@master/icons-react/24/soft';
<SearchIcon size={48} strokeWidth={2} />
```

各光學尺寸支援的範圍與繪製方式，請見[線寬](/guide/stroke-width)。
