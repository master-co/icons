## 설치 \{#install\}

프레임워크에 맞는 패키지를 설치하세요. 각 패키지는 공통 코어인 `@master/icons`를 함께 설치하며 앱에 이미 설치된 프레임워크를 사용합니다.

| 프레임워크 | 패키지 |
| --- | --- |
| React 18 또는 19 | `@master/icons-react` |
| Vue 3.5 이상 | `@master/icons-vue` |
| Svelte 5 | `@master/icons-svelte` |
| Preact 11 | `@master/icons-preact` |
| Astro 7 | `@master/icons-astro` |
| 프레임워크 없음 | `@master/icons` |

```sh
npm install @master/icons-react
```

다른 패키지 관리자를 쓴다면 같은 패키지 이름으로 `bun add`, `pnpm add` 또는 `yarn add`를 실행하세요. 사용하는 프레임워크용 패키지 하나면 됩니다. Node.js 22 이상을 지원하며 Astro 패키지는 Node.js 24 이상이 필요합니다.

## 아이콘 표시하기 \{#first-icon\}

아이콘을 이름으로 가져오세요. 아이콘 컴포넌트 이름은 `Icon`으로 끝납니다.

```tsx
import { SearchIcon } from '@master/icons-react';

<SearchIcon size={20} label="Search" />
```

색상은 `currentColor`로 주변 글자색을 따릅니다. 별도 옵션이 없으면 살짝 둥근 모서리의 24 px 원본을 표시합니다. [컬렉션](/icons)에서 모든 이름을 찾아보고 가져오기 코드를 복사하거나 SVG 파일을 다운로드하세요.

## 진입점 선택하기 \{#entries\}

각 패키지는 동일한 아이콘 이름을 사용하는 두 가지 진입점을 제공합니다.

- **동적 진입점**(예: `@master/icons-react`). 각 아이콘은 원본 9종(크기 3가지 × 모서리 3가지)을 포함하며 `size`, `corner`, `strokeWidth`를 받습니다.
- **고정 진입점**(예: `@master/icons-react/20/soft`). 각 아이콘은 원본 한 가지만 포함합니다. 인터페이스 전체에서 같은 크기와 모서리를 쓸 때 전송 용량을 줄일 수 있습니다.

```tsx
import { SearchIcon } from '@master/icons-react/20/soft';

<button aria-label="Search"><SearchIcon /></button>
```

트리 셰이킹을 지원하는 번들러는 사용하지 않는 아이콘을 제거합니다. 환경에 맞는 [SVG와 JavaScript](/guide/svg), [React](/guide/react), [Vue](/guide/vue), [Svelte](/guide/svelte), [Preact](/guide/preact), [Astro](/guide/astro) 가이드로 이동하세요.

## AI 에이전트로 설정하기 \{#set-up-with-an-ai-agent\}

## AI 에이전트용 자료 \{#ai-agents\}

실제 아이콘 이름과 사용 규칙을 확인할 수 있는 두 가지 자료가 있습니다.

- **에이전트 스킬.** `@master/icons`에는 `node_modules/@master/icons/skills/master-icons/SKILL.md`가 포함되어 있습니다. `master-icons` 폴더를 `.claude/skills` 또는 `.agents/skills` 같은 스킬 디렉터리에 복사하세요. 패키지, 진입점, 크기, 선 두께, 접근성 설명과 설치된 카탈로그에서 실제 이름을 검색하는 스크립트가 들어 있습니다. 예: `node node_modules/@master/icons/skills/master-icons/scripts/search.mjs search`.
- **llms.txt.** [/ko/llms.txt](/ko/llms.txt)는 모든 가이드의 Markdown 색인이며 [/ko/llms-full.txt](/ko/llms-full.txt)는 전문을 한 파일로 제공합니다. [/ko/guide/getting-started.md](/ko/guide/getting-started.md)처럼 각 가이드 주소에 `.md`를 붙여도 됩니다.
