## Install \{#install\}

Install the package for your framework. Each framework package brings the shared `@master/icons` core with it and uses the framework already in your application.

| Framework | Package |
| --- | --- |
| React 18 or 19 | `@master/icons-react` |
| Vue 3.5 or later | `@master/icons-vue` |
| Svelte 5 | `@master/icons-svelte` |
| Preact 11 | `@master/icons-preact` |
| Astro 7 | `@master/icons-astro` |
| No framework | `@master/icons` |

```sh
npm install @master/icons-react
```

With other package managers, use `bun add`, `pnpm add` or `yarn add` with the same name. Install only the package for your framework; the others are not needed. The packages support Node.js 22 and later, and the Astro package requires Node.js 24 or later.

## Render an icon \{#first-icon\}

Import each icon by name. Icon components end in `Icon`.

```tsx
import { SearchIcon } from '@master/icons-react';

<SearchIcon size={20} label="Search" />
```

Icons draw in `currentColor`, so they take the color of the surrounding text. Without options, an icon renders the 24 px drawing with soft corners. Browse every name, copy its import and download SVG files in the [collection](/icons).

## Choose an entry \{#entries\}

Each package has two kinds of entry, with the same icon names:

- **Dynamic**, such as `@master/icons-react`: each icon carries all nine drawings (three optical sizes by three corner styles) and accepts `size`, `corner` and `strokeWidth`.
- **Fixed**, such as `@master/icons-react/20/soft`: each icon carries one drawing. Use it when the whole interface uses one size and corner style; it ships less.

```tsx
import { SearchIcon } from '@master/icons-react/20/soft';

<button aria-label="Search"><SearchIcon /></button>
```

Unused icons are removed by any bundler that supports tree shaking. Continue with the page for your framework: [SVG and JavaScript](/guide/svg), [React](/guide/react), [Vue](/guide/vue), [Svelte](/guide/svelte), [Preact](/guide/preact) or [Astro](/guide/astro).
