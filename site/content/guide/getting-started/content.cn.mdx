## 安装 \{#install\}

安装对应框架的包。每个框架包都会一并安装共用的 `@master/icons` 核心，并使用应用程序中现有的框架。

| 框架 | 包 |
| --- | --- |
| React 18 或 19 | `@master/icons-react` |
| Vue 3.5 以上 | `@master/icons-vue` |
| Svelte 5 | `@master/icons-svelte` |
| Preact 11 | `@master/icons-preact` |
| Astro 7 | `@master/icons-astro` |
| 不使用框架 | `@master/icons` |

```sh
npm install @master/icons-react
```

使用其他包管理器时，以相同名称运行 `bun add`、`pnpm add` 或 `yarn add`。只需安装所用框架的包，不需要其他框架包。包支持 Node.js 22 及以上版本，Astro 包则需要 Node.js 24 及以上版本。

## 显示图标 \{#first-icon\}

按名称导入每个图标。图标组件名称以 `Icon` 结尾。

```tsx
import { SearchIcon } from '@master/icons-react';

<SearchIcon size={20} label="搜索" />
```

图标以 `currentColor` 绘制，因此会采用周围文本的颜色。默认显示 24 px 的微圆角图稿。在[图标库](/icons)中可浏览所有名称、复制导入用法并下载 SVG 文件。

## 选择入口 \{#entries\}

每个包都有两种入口，图标名称相同：

- **动态入口**，例如 `@master/icons-react`：每个图标包含全部九份图稿（三种光学尺寸与三种边角样式的组合），并接受 `size`、`corner` 与 `strokeWidth`。
- **固定入口**，例如 `@master/icons-react/20/soft`：每个图标只包含一份图稿。如果整个界面使用相同的尺寸和边角样式，可选固定入口以减小打包体积。

```tsx
import { SearchIcon } from '@master/icons-react/20/soft';

<button aria-label="搜索"><SearchIcon /></button>
```

支持 tree shaking 的打包工具会移除未使用的图标。接着请阅读所用框架的页面：[SVG 与 JavaScript](/guide/svg)、[React](/guide/react)、[Vue](/guide/vue)、[Svelte](/guide/svelte)、[Preact](/guide/preact) 或 [Astro](/guide/astro)。

## AI 智能体资源 \{#ai-agents\}

编程智能体可以通过以下两项资源查找实际存在的图标，并按上述规则使用：

- **智能体技能。** `@master/icons` 附带智能体技能：`node_modules/@master/icons/skills/master-icons/SKILL.md`。将 `master-icons` 文件夹复制到智能体的 skills 文件夹，例如 `.claude/skills` 或 `.agents/skills`。内容涵盖包、入口、尺寸、线宽与无障碍，并附有用于搜索本地目录的脚本，让智能体不会编造图标名称：`node node_modules/@master/icons/skills/master-icons/scripts/search.mjs search`。
- **llms.txt。** [/cn/llms.txt](/cn/llms.txt) 以 Markdown 列出每篇指南，[/cn/llms-full.txt](/cn/llms-full.txt) 则将全文合为一个文件。每篇指南的网址添加 `.md` 即可获取 Markdown 版，例如 [/cn/guide/getting-started.md](/cn/guide/getting-started.md)。
