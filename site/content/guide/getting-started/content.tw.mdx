## 安裝 \{#install\}

安裝對應框架的套件。每個框架套件都會一併安裝共用的 `@master/icons` 核心，並使用應用程式中既有的框架。

| 框架 | 套件 |
| --- | --- |
| React 18 或 19 | `@master/icons-react` |
| Vue 3.5 以上 | `@master/icons-vue` |
| Svelte 5 | `@master/icons-svelte` |
| Preact 11 | `@master/icons-preact` |
| Astro 7 | `@master/icons-astro` |
| 不使用框架 | `@master/icons` |

```sh
npm install @master/icons-react
```

使用其他套件管理工具時，以相同名稱執行 `bun add`、`pnpm add` 或 `yarn add`。只需安裝所用框架的套件，不需要其他框架套件。套件支援 Node.js 22 以上，Astro 套件則需要 Node.js 24 以上。

## 呈現圖示 \{#first-icon\}

以名稱匯入每個圖示。圖示元件名稱以 `Icon` 結尾。

```tsx
import { SearchIcon } from '@master/icons-react';

<SearchIcon size={20} label="Search" />
```

圖示以 `currentColor` 繪製，因此會採用周圍文字的顏色。未指定選項時，圖示呈現微圓角的 24 px 圖稿。在[圖庫](/icons)可瀏覽所有名稱、複製匯入用法並下載 SVG 檔案。

## 選擇入口 \{#entries\}

每個套件都有兩種入口，圖示名稱相同：

- **動態入口**，例如 `@master/icons-react`：每個圖示包含全部九份圖稿（三種光學尺寸乘以三種圓角），並接受 `size`、`corner` 與 `strokeWidth`。
- **固定入口**，例如 `@master/icons-react/20/soft`：每個圖示只包含一份圖稿。整個介面使用同一種尺寸與圓角時使用，體積更小。

```tsx
import { SearchIcon } from '@master/icons-react/20/soft';

<button aria-label="Search"><SearchIcon /></button>
```

支援 tree shaking 的打包工具會移除未使用的圖示。接著請閱讀所用框架的頁面：[SVG 與 JavaScript](/guide/svg)、[React](/guide/react)、[Vue](/guide/vue)、[Svelte](/guide/svelte)、[Preact](/guide/preact) 或 [Astro](/guide/astro)。

## 以 AI agent 設定 \{#set-up-with-an-ai-agent\}

Coding agent 可以替你完成設定。在應用程式根目錄啟動 agent，再貼上下方提示詞：它會先檢查專案，並在修改檔案前詢問框架套件、預設尺寸、圓角與線寬，以及既有圖示庫的處理方式。接著安裝套件、呈現第一個圖示並執行專案檢查。

## 給 AI agent \{#ai-agents\}

有兩項資源能讓 coding agent 使用真實的圖示名稱，並遵守上述規則：

- **Agent skill。** `@master/icons` 內附 skill：`node_modules/@master/icons/skills/master-icons/SKILL.md`。將 `master-icons` 資料夾複製到 agent 的 skills 資料夾，例如 `.claude/skills` 或 `.agents/skills`。內容涵蓋套件、入口、尺寸、線寬與無障礙，並附有搜尋已安裝 catalog 的腳本，讓 agent 不會編造圖示名稱：`node node_modules/@master/icons/skills/master-icons/scripts/search.mjs search`。
- **llms.txt。** [/tw/llms.txt](/tw/llms.txt) 以 Markdown 列出每篇指南，[/tw/llms-full.txt](/tw/llms-full.txt) 則將全文合為一個檔案。每篇指南的網址加上 `.md` 即可取得 Markdown 版，例如 [/tw/guide/getting-started.md](/tw/guide/getting-started.md)。
