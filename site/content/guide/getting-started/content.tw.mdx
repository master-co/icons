## 使用本機 workspace \{#workspace\}

Master Icons 目前為 private alpha，尚未發布至 npm。在此 monorepo 的應用程式依賴中加入使用的框架套件，例如 `"@master/icons-svelte": "workspace:*"`（SVG／JavaScript 則使用 `"@master/icons": "workspace:*"`），然後執行：

```sh
bun install
bun run build:icons
```

若要在其他專案使用，先在此儲存庫產生封裝檔案，再安裝核心與使用的框架套件（以下以 Svelte 為例）：

```sh
bun run pack:icons
# In your application:
bun pm pkg set "overrides.@master/icons=file:/absolute/path/to/master-icons/work/master-icons-alpha.tgz"
bun add /absolute/path/to/master-icons/work/master-icons-alpha.tgz /absolute/path/to/master-icons/work/master-icons-svelte-alpha.tgz
```

private alpha 尚未發布至 npm，因此本機 override 也會將框架套件的核心依賴指向封裝檔。請將絕對路徑換成你的儲存庫位置。

套件支援 Node.js 22 以上；開發此儲存庫使用 Node.js 24 與 Bun 1.4.4。

## 選擇接入方式 \{#integration\}

任何框架都可使用 [SVG 或 JavaScript](/guide/svg)，也可選擇 [React](/guide/react)、[Vue](/guide/vue)、[Svelte](/guide/svelte)、[Preact](/guide/preact) 或 [Astro](/guide/astro) 元件。每個框架都有獨立的 `@master/icons-{framework}` 套件，依賴共用圖稿的 `@master/icons` 核心。只需安裝使用的圖示套件與對應框架，其他框架套件不會一併安裝。框架工具可能需要較新的 Node.js 版本。

預設從 24px 與微圓開始。密集介面可選 16px 或 20px 的光學圖稿，詳見[尺寸與圓角](/guide/optical-sizes)。
