## インストール \{#install\}

お使いのフレームワーク用パッケージをインストールします。各パッケージは共通のコア `@master/icons` を依存関係に持ち、アプリに導入済みのフレームワークを使います。

| フレームワーク | パッケージ |
| --- | --- |
| React 18 または 19 | `@master/icons-react` |
| Vue 3.5 以降 | `@master/icons-vue` |
| Svelte 5 | `@master/icons-svelte` |
| Preact 11 | `@master/icons-preact` |
| Astro 7 | `@master/icons-astro` |
| フレームワークなし | `@master/icons` |

```sh
npm install @master/icons-react
```

ほかのパッケージマネージャーでは、同じ名前で `bun add`、`pnpm add`、`yarn add` を使います。選んだフレームワーク用のパッケージひとつで十分です。Node.js 22 以降に対応し、Astro 用パッケージは Node.js 24 以降が必要です。

## アイコンを表示する \{#first-icon\}

アイコンを名前でインポートします。コンポーネント名の末尾は `Icon` です。

```tsx
import { SearchIcon } from '@master/icons-react';

<SearchIcon size={20} label="検索" />
```

色は `currentColor` で周囲の文字色に合わせます。指定しなければソフトな角の 24 px の原図が表示されます。[コレクション](/icons)ではすべての名前を調べ、インポート文をコピーしたり SVG をダウンロードしたりできます。

## エントリーを選ぶ \{#entries\}

各パッケージには同じアイコン名を使う 2 種類のエントリーがあります。

- **動的**（例：`@master/icons-react`）。各アイコンは 9 種の原図（3 サイズ × 3 種類の角）を含み、`size`、`corner`、`strokeWidth` を受け取ります。
- **固定**（例：`@master/icons-react/20/soft`）。各アイコンの原図は 1 種類です。同じサイズと角で UI を統一するときに使うと、配信サイズが小さくなります。

```tsx
import { SearchIcon } from '@master/icons-react/20/soft';

<button aria-label="検索"><SearchIcon /></button>
```

ツリーシェイキング対応のバンドラーは未使用のアイコンを除去します。環境に応じて [SVG と JavaScript](/guide/svg)、[React](/guide/react)、[Vue](/guide/vue)、[Svelte](/guide/svelte)、[Preact](/guide/preact)、[Astro](/guide/astro) に進んでください。

## AI エージェント向けの資料 \{#ai-agents\}

実在するアイコン名と正しい使い方を確認できる資料が 2 つあります。

- **エージェントスキル**： `@master/icons` は `node_modules/@master/icons/skills/master-icons/SKILL.md` を同梱します。`master-icons` フォルダーを `.claude/skills` や `.agents/skills` などのスキルディレクトリにコピーしてください。パッケージ、エントリー、サイズ、線幅、アクセシビリティの説明と、インストール済みカタログを検索するスクリプトが含まれます。例：`node node_modules/@master/icons/skills/master-icons/scripts/search.mjs search`。
- **llms.txt**： [/ja/llms.txt](/ja/llms.txt) は全ガイドの Markdown 索引です。[/ja/llms-full.txt](/ja/llms-full.txt) には全文がまとまっています。[/ja/guide/getting-started.md](/ja/guide/getting-started.md) のように、各ガイドの URL に `.md` を付けても読めます。
