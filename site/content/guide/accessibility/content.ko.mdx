## 컨트롤에 이름 지정하기 \{#controls\}

텍스트 옆의 아이콘은 장식으로 처리합니다. `label`을 생략하면 렌더러가 `aria-hidden="true"`를 설정합니다. 아이콘만 있는 버튼에는 버튼 자체에 접근 가능한 이름을 지정하세요.

```tsx
<button aria-label="Search"><SearchIcon size={20} /></button>
```

## 독립적인 아이콘에 이름 지정하기 \{#standalone\}

아이콘 자체가 정보를 전달하면 `label`을 지정하세요. 렌더러가 `role="img"`와 접근 가능한 이름을 추가합니다.

```tsx
<SearchIcon label="Search" />
```

상태는 색만으로 구분하지 말고 중요한 설명은 텍스트로도 제공하세요. 키보드 초점이 보이도록 하고 누를 수 있는 영역을 충분히 확보하세요.
