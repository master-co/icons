## 动态图标 \{#dynamic\}

Vue 是必需的对等依赖。请在应用中安装 Vue 3.5 以上的 3.x 版本，并[安装 `@master/icons-vue`](/guide/getting-started#install)。

```vue
<script setup lang="ts">
import { SearchIcon } from '@master/icons-vue';
</script>

<template>
  <SearchIcon :size="20" corner="rounded" label="搜索" />
</template>
```

从动态入口导入的每个图标都包含九种光学尺寸与边角样式的组合，以及每种组合支持的线宽变体。各框架与 SVG 使用相同的图形数据。`size` 会选择最接近的光学图稿；`corner` 默认为 `soft`。

## 固定图标 \{#fixed\}

```vue
<script setup lang="ts">
import { SearchIcon } from '@master/icons-vue/16/soft';
</script>

<template>
  <button aria-label="搜索"><SearchIcon /></button>
</template>
```

固定入口只包含一种光学尺寸和边角样式的组合。可将 `16/soft` 换成 `16`、`20`、`24` 与 `sharp`、`soft`、`rounded` 的任意组合。固定组件不接受 `corner` 或 `opticalSize`；`size` 只会缩放所选图稿。

## 框架特性 \{#behavior\}

在模板中使用 `optical-size`，例如 `:optical-size="16"`。SVG 属性与事件监听器会传给 SVG 根元素。图标为函数组件，组件 ref 并不是 SVG 元素 ref。

没有标签的图标会被视为装饰。对于需要表达含义的图标，可以使用 `label`、`aria-label` 或 `aria-labelledby`，也可以为外层按钮命名，详见[无障碍](/guide/accessibility)。

## 自定义线宽 \{#stroke-width\}

动态与固定入口都接受 `strokeWidth`，以原图坐标为单位，步长为 0.25。它会根据线宽选择单独绘制的图稿。

```vue
<script setup lang="ts">
import { SearchIcon } from '@master/icons-vue/24/soft';
</script>

<template>
  <SearchIcon :size="48" :stroke-width="2" />
</template>
```

各光学尺寸支持的线宽范围和绘制方法，参见[线宽](/guide/stroke-width)。
