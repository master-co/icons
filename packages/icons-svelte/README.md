# @master/icons-svelte

Master Icons components for Svelte. This private alpha is not published to npm.

This package contains only the Svelte adapter. It depends on the matching `@master/icons` core for shared geometry and requires `svelte` as its only framework peer. It does not install the other icon adapters.

In this monorepo, add `"@master/icons-svelte": "workspace:*"`. For an external project, run `bun run pack:icons` at the repository root and install both local archives:

```sh
bun pm pkg set "overrides.@master/icons=file:/absolute/path/to/work/master-icons-alpha.tgz"
bun add /absolute/path/to/work/master-icons-alpha.tgz /absolute/path/to/work/master-icons-svelte-alpha.tgz
```

```js
import { SearchIcon } from '@master/icons-svelte';
import { SearchIcon as SmallSearch } from '@master/icons-svelte/16/soft';
```

Dynamic components select among 16, 20 and 24 px optical sizes and sharp, soft and rounded corners. Fixed imports contain one drawing and still accept a display `size`. Unused icons can be tree-shaken. Direct component imports are also available at `@master/icons-svelte/icons/search` and `@master/icons-svelte/16/soft/search`.

Native components are compiled by your application’s Svelte tooling. See the [shared usage guide](../icons/README.md) for props, accessibility, direction and framework examples. Geometry and its applicable artwork notices are supplied by `@master/icons`; code is MIT licensed.

Sources live in `src/`; `dist/` is generated by `bun run build`. Do not edit generated files.
